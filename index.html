Pengaturan Koneksi Google Sheets

Tempel URL Web App dari Google Apps Script di sini.

URL API

Cara mendapatkan URL ini: buka Google Sheets → Extensions > Apps Script → tempel kode Code_GoogleAppsScript.gs → Deploy > New deployment (Web app, akses "Anyone") → salin URL → tempel di kolom atas.

Data tersimpan langsung di Google Sheets Anda. Foto disimpan sebagai link Google Drive/Google Photos di kolom Foto.
